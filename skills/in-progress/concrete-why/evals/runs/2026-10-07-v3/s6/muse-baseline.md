In NRO `Stamina == 0` inside Hora would be the special case; the tag is the general form — [ADR 0038](file:///home/ozzy-desktop/dev/NRO/docs/adr/0038-an-empty-resource-bar-is-a-gameplay-tag.md):

1. **Everything already speaks tags:** Hora's flurry is `firstOf(onInputReleased, after(hold), onTagAdded(EmptyTag))` in [Hora.Ability.ts](/home/ozzy-desktop/dev/NRO/src/Shared/ReplicatedStorage/Content/GameplayAbilities/Hora.Ability.ts:135). Activation gates, `runsWhileTagged` effect conditions, and cues can all read that same tag. A `stamina == 0` check only helps Hora; an `onAttributeEmpty()` race would still leave gates/cues/conditions needing their own copies.
2. **One owner, no disagreement:** the attribute container owns the number, so it owns the moment it hits its floor. Every write goes through `recordChange()` → `emptyTags.Settle()` in [GameplayAttributeContainer.ts](/home/ozzy-desktop/dev/NRO/src/Shared/ReplicatedStorage/GameplayAttributes/GameplayAttributeContainer.ts:649), so number and tag flip atomically. Polling from the ability infers state from a side effect — forbidden by `AGENTS.md` ("Take the dependency") — and races when the check runs between changes.
3. **"Empty" isn't always `0`:** `Health` floors at `1`, `Stamina` at `0` in [Resources.GameplayAttribute.ts](/home/ozzy-desktop/dev/NRO/src/Shared/ReplicatedStorage/Content/GameplayAttributes/Resources.GameplayAttribute.ts:106). `WhileEmpty` means "at lower limit", abstracted in [EmptyTag.ts](/home/ozzy-desktop/dev/NRO/src/Shared/ReplicatedStorage/GameplayAttributes/EmptyTag.ts:60).
4. **Prediction is free:** the container is shared code, so client's guess at "empty" comes from the same change the server confirms.
