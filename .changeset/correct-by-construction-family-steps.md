**`correct-by-construction`** now handles a family of things built the same way, such as discount types, transaction types or form submissions. It lists the steps every member goes through, marks each step as shared or written per member, and calls a class closed only when its step is one shared function that members configure by declaration. When one member runs in two places, such as a client and a server, values may differ but code paths may not. The report opens with that list of steps as a table. A new reference, `references/family-steps.md`, works through four families.
