**`correct-by-construction`** reports each class as a short block instead of three paragraphs: the answer in one bold sentence, then for each class a bold label naming what happens and one-line bullets for Now, Where, Class, Fix, Can't come back and Proof, ending with what needs the reader. It also never prescribes a runtime limit, counter or alarm that fires if the bad state returns: the bad state is made unwritable, and the proof is a test or static check that runs before the code lands.
