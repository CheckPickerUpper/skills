**`facts-as-data`**: the census reads code in every language (Zig, Odin, Nim, Julia, OCaml, Vue, extensionless scripts and any other text file) instead of a fixed list of extensions, skipping only prose, data, lockfiles, minified or generated files, media and binaries. A path that gives it nothing to read (a typo, test files only, or only files that are not code) now exits 2 naming the path and what it matched, instead of reporting "No unsettled leads".
